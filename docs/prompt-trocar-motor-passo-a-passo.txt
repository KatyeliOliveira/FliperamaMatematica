================================================================
PASSO 1 — Baixar o motor publicado
================================================================
Baixe com o terminal (PowerShell) para uma pasta TEMP, NÃO em cima do jogo ainda:

$ref = "$env:TEMP\jogos-ref"
New-Item -ItemType Directory -Force -Path $ref | Out-Null
$base = "https://jogosmilena.felipe-conhariki.workers.dev"
Invoke-WebRequest "$base/" -OutFile "$ref\index.html" -UseBasicParsing
try { Invoke-WebRequest "$base/manifest.json" -OutFile "$ref\manifest.json" -UseBasicParsing } catch {}
try { Invoke-WebRequest "$base/sw.js" -OutFile "$ref\sw.js" -UseBasicParsing } catch {}
try { Invoke-WebRequest "$base/worker.js" -OutFile "$ref\worker.js" -UseBasicParsing } catch {}
try { Invoke-WebRequest "$base/wrangler.jsonc" -OutFile "$ref\wrangler.jsonc" -UseBasicParsing } catch {}

Leia o index.html baixado. Ele é um app único (HTML+CSS+JS). Confirme que existem:
- const THEMES={...}
- function buildGames()
- Mundo Aberto (openWorld, Three.js voxel)
- Pinball 3D (pinball / pinball2d)
- Stick Fight (stickArena / stickFighter)
- Cat Escape (catEscape)
- Estúdio do Avatar (dressUp / avatarStudio)
- Xadrez e Dama
- sync de progresso (SV_ / jp_sv)

Se o download falhar, tente de novo. Não invente o 3D do zero.

================================================================
PASSO 2 — Inventariar ESTA pasta (o jogo dela)
================================================================
Liste os arquivos da pasta aberta. Ache o HTML/JS principal.

Extraia e GUARDE (em memória / arquivo temporário) o conteúdo DELA, que não pode se perder:
- Objeto THEMES (personagens, cores, palavras, quiz, falas, ícones)
- Personagens extras (TORAJO_EXTRA ou equivalente dela)
- Título, manifest name, theme-color, ícones PNG se forem dela
- Qualquer texto/nota específica (nome das crianças, etc.)
- worker/sync URLs se ela já tiver nuvem própria

Se ela NÃO tiver THEMES estruturado, extraia personagens/perguntas do jeito que estiver e monte no formato do motor novo.

================================================================
PASSO 3 — Trocar o motor, manter o conteúdo
================================================================
Substitua o motor local pelo index.html de referência (o baixado).

DEPOIS, recoloque o THEMES DELA no lugar do THEMES de referência.
NÃO deixe os temas do site (Torajo, Demon Slayer, Naruto, etc.) a menos que ela já tivesse esses temas.

Formato obrigatório de cada tema (preencha o que faltar com conteúdo original, sem copiar letra de música nem fala oficial):

chave: {
  name, short, icon, tune, sym ('fruta' ou 'símbolo'), art ('a' ou 'o'),
  bg, acc, accD, line, cream,
  float: [6 emojis de fundo],
  cheer, gameIcons: {memory, catcher, slicer, simon, cards, domino},
  note,
  chars: [ mk('Nome','emoji','tag',[3 pistas],[3 falas],pitch,rate), ... ],
  words: [['palavra','dica'], ...],   // ~16+
  quiz: [{q,a,o:[4 opções]}],         // ~6+
  tf: [{t,a:true/false}],             // ~6+
  intr: [{q,o,a,x}],                  // 3+
  mil: { med:[], hard:[], top:[] }    // Rumo ao Milhão
}

Função mk já existe no motor. Personagens: 7–13 por tema.

Ajuste também:
- applyTheme default para o tema principal DELA (não 'torajo', a menos que seja o dela)
- manifest.json: name/short_name/cores/ícones do jogo DELA
- sw.js: nome do cache diferente (ex: jogos-milena-v25) para forçar atualização no celular
- FS_SITE e URLs de sync: mantenha as dela se existirem; senão use o próprio workers.dev em que ela publica
- Título <title> e h1 “Jogos de …”

NÃO apague: Mundo Aberto, Pinball 3D, Stick Fight, Cat Escape, Avatar, Tetris, Dança, Xadrez, Dama, Bingo, etc.
